# 가스기능사 필기

가스기능사 필기 기출 19회차(2015~2022) 1,140문항 + 이론 예상문제로 연습·종합시험·CBT 실전을 푸는 도구입니다.

- 주소 : https://hongyul67-cpu.github.io/gas-craftsman-cbt/ (암호 잠금)
- 대상 : 가스기능사 필기 준비
- 만든 날 : 2026-11-27

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 범위 고르기(회차 × 과목) → 연습 8문항 → 종합시험 20문항 → CBT 실전 60문항·60분 → 오답노트 → 제출 |
| `data/bank.js` | 문제은행 (자동 생성 · **커밋하지 않음**) |
| `build_bank.py` | 전사본 JSON → `data/bank.js` 굽기 |
| `bank.enc` | 배포되는 문제은행 — AES-GCM 암호화 |
| `build_lock.py` | `data/bank.js` → `bank.enc` 굽기 |
| `rubric.json` | 결과수집이 세특 문장·성취수준을 만들 때 쓰는 평가 루브릭 |

## 문제은행 굽기

```
cd "..\_작업\가스기능사 전사"
python 검수.py            # 과목·중복·법령 표시 → _src/문항/_검수.json
cd "..\..\가스기능사 필기 CBT"
python build_bank.py      # → data/bank.js
python build_lock.py      # → bank.enc (교사용 암호는 _weekly/secret.json)
```

읽는 곳 : `../_작업/가스기능사 전사/_src/문항/` 의 `gi-*.json`(기출 19회) · `th-*.json`(이론 예상문제) · `_검수.json`

| 칸 | 뜻 |
|---|---|
| `i` `r` `n` `p` | 아이디 · 회차/챕터 · 책 문제 번호 · 책 쪽 |
| `q` `o` `a` `e` | 발문 · 보기 4개 · 정답(0부터) · 해설 |
| `u` | 과목 — 안전(가스 안전관리) · 장치(가스장치 및 기기) · 일반(가스일반). 문제 내용으로 나눔 |
| `d` | 앞 회차와 같은 문제면 먼저 나온 아이디 — **연습·종합 무작위 출제에서 뺀다** (CBT 실전은 회차 그대로) |
| `l` | 법령이 바뀌었을 수 있는 문항 메모 — 해설 아래 ⚖️ 한 줄로 보임. 정답은 교재대로 |
| `x` | 1이면 보기를 섞지 않는다 (해설이 「①, ③은…」 처럼 보기 번호를 가리키는 문항) |

검수 결과는 `_작업/가스기능사 전사/검수보고.md`.
